How this works

  • Click New top-level category to start a fresh branch, like "Radiology" or "Legal & Compliance".
  • Use the folder-plus icon on any row to nest a sub-category underneath it — repeat endlessly for N-level depth.
  • The pencil renames in place; the trash removes that node and everything nested inside it.
  • This exact tree powers the picker shown during document upload.
